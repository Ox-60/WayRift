# CDC — MetiersModule (V2)

> Plugins : **AdvancedJobs** + **AdvancedSkills**. Progression naturelle par la pratique — pas de points à dépenser, le niveau reflète l'activité réelle du joueur.

## Rôle des deux plugins — Clarification technique

Ces deux plugins ont des rôles **différents et complémentaires**, pas redondants :

| Plugin | Rôle | Noms |
|---|---|---|
| **AdvancedJobs** | Système de métiers/jobs — gagner de l'argent en pratiquant une profession | **Entièrement personnalisable** — pas de noms fixes imposés par le plugin. Nos métiers (Médecin, Assassin, Mécanicien...) sont construits ici via des actions configurées |
| **AdvancedSkills** | Système de compétences RPG — 14 compétences natives qui montent en niveau passivement et débloquent des Talents | **Noms fixes imposés par le plugin** (voir tableau ci-dessous) |

### Les 14 compétences natives d'AdvancedSkills

| Compétence | Catégorie | Lien avec nos métiers custom |
|---|---|---|
| Mining | Récolte | Mineur (Artisanat) |
| Excavation | Récolte | Mineur (Artisanat) |
| Fishing | Récolte | Pêcheur (Culture, V3+) |
| Herbalism | Récolte | Herboriste (Culture, V3+) |
| Woodcutting | Récolte | — (pas de métier bois dédié actuellement) |
| Swords | Combat | Guerrier (Guerre) |
| Axes | Combat | Guerrier (Guerre) |
| Archery | Combat | Éclaireur (Guerre) |
| Crossbow | Combat | Éclaireur (Guerre) |
| Trident | Combat | Guerrier (Guerre) — contexte aquatique |
| Defense | Combat | Guerrier, Robustesse (Guerre) |
| Acrobatics | Utilitaire | Assassin, Éclaireur (Guerre) — furtivité/agilité |
| Alchemy | Utilitaire | Médecin, Occultiste (Mysticisme) |
| Elytra | Utilitaire | — (pas de métier vol dédié actuellement) |

> **AdvancedSkills tourne en arrière-plan pour tous les joueurs**, indépendamment du métier choisi via AdvancedJobs — un Guerrier montera naturellement Swords/Axes/Defense en combattant, un Mineur montera Mining/Excavation en minant. Les deux systèmes se renforcent mutuellement sans être redondants : AdvancedJobs = identité de métier + revenus, AdvancedSkills = compétence physique/technique qui en découle naturellement.

## Feuille de route — Ce qui est nécessaire quand

### Saison 2 — Requis
- Les 4 branches de métiers de base (Mysticisme, Guerre, Artisanat, Culture) + Divers
- Progression par la pratique, sans système de spécialisation complète

### Saison 3+ — Spécialisations complètes
- Les branches deviennent incomplètes intentionnellement en V2/V3 — finalisation en V6 (voir Roadmap générale)

---

## Principe de progression

```
Pas de points à dépenser — le niveau de métier reflète l'activité réelle :
  Miner -> monte le niveau Mineur
  Pêcher -> monte le niveau Pêcheur
  Soigner -> monte le niveau Médecin
  etc.
```

## Arbre des métiers — 5 branches

| Branche | Métier de base | Spécialisation 1 | Spécialisation 2 | Spécialisation 3 |
|---|---|---|---|---|
| **Mysticisme** | — | Médecin/Clerc (soins, revive) | Occultiste/Nécromancien (poisons, malédictions) | — |
| **Guerre** | — | Assassin (furtivité, rapidité) | Éclaireur (vision, archerie, agilité) | Guerrier (force, robustesse) |
| **Artisanat** | Mineur (base minage) | Mécanicien (machines, quarries — V6) | Canalisateur (redstone avancée) | Forgeron (forge, armes, armures) |
| **Culture** | — | Herboriste (plantes, drogues — V3+) | Agriculteur (nourriture, céréales) | Pêcheur (pêche, poissons rares — V3+) |
| **Divers** | Horloger | Contrôle d'un Pantin NPC, vote nuit | — | — |

> Herboriste et Pêcheur nécessitent V3+ pour leurs mécaniques complètes (drogues, poissons rares) — accessibles dès V2 en version basique.
