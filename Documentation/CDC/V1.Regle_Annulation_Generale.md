# Règle générale — Annulation en cas de rupture

> Règle transversale appliquée à TOUS les CDC : déconnexion, suppression de faction, conflit de claim, ou toute autre rupture en cours d'action.

---

## Principe

**Dans la majorité des cas, l'action en cours est simplement ANNULÉE** — pas de tentative de résolution complexe, pas d'état intermédiaire ambigu. C'est le comportement par défaut, sauf mention contraire explicite dans un CDC spécifique.

```
Exemples d'application :
  - Joueur se déconnecte pendant une transaction HDV -> transaction annulée
  - Faction supprimée pendant qu'un contrat B2B est actif -> contrat annulé
  - Deux joueurs tentent de claim la même zone simultanément -> la 2e tentative échoue, annulée
  - Joueur déconnecté pendant une capture de claim -> capture annulée (défenseur gagne par défaut)
  - Vendeur déconnecté pendant une vente HDV -> transaction annulée, item reste dans son slot
```

**Aucun remboursement automatique garanti** sauf mention contraire — si un coût a déjà été prélevé avant la rupture (ex: coût de capture déjà payé), il suit la règle définie dans le CDC concerné (ex: capture = coût perdu même en cas d'échec, donc une déconnexion pendant la capture suit la même règle que n'importe quel échec).
